# 《可视化导论》课程门户 · 重构版

对 [原版课程门户](https://cinger007.github.io/vis/) 的完整重构。
原版是"讲解 / 关键代码 / 演示"三个 Tab 切换的结构;重构版把每个知识点改为
**讲解 → 代码 → 可交互演示纵向连排**的一体化页面,并新增课程学习路径图等可视化。

## 重构要点

| 维度 | 原版 | 重构版 |
|------|------|--------|
| 知识点呈现 | 三 Tab 割裂,来回切换 | 讲解/代码/演示纵向连排,一一对应 |
| 首页 | 章节卡片列表 | SVG 学习路径图(四阶段)+ 章节卡片 + 课程统计 |
| 演示 | 静态演示 | 29 个可交互演示:可调参数、悬停取值、刷选联动、FPS 实测 |
| 代码块 | 展示 | 语法高亮 + 一键复制 |
| 导航 | Tab | 左侧目录随滚动高亮 + 章末上一章/下一章 |
| 体积 | — | 纯静态、零依赖、无视频,正文资源约 350KB |

## ✦ 学习星图(首页 #starmap 区块)—— 课程的最后一件展品是学生自己

首页 **"学习路径 / 课程章节 / 学习星图 / 使用方式"** 中的"学习星图"即是一座内嵌首页的"天文馆":

- **9 个星座 = 9 章,29 颗星 = 29 个知识点**,沿一条正弦学习之路排布
- 星的**亮度与大小四级编码掌握度**:未读(暗尘)→ 已读(微光)→ 动手玩过演示(彩色光环)→ 随堂一问答对(金色十字);答错挂红色虚线环,回去重做即可点亮
- **悬停**显示这一节的阅读/演示/答题状态,**点击直达原知识点**
- 右侧**观测报告**:点亮进度、演示互动数、随堂一问正确率、学习时长、鼠标里程(米)、滚动距离(米/篮球场)——原始 px 数据经过单位换算才可读
- **29/29 全点亮 → 黎明模式**:夜空渐变破晓 + 烟花 + "这门课的最后一幅图是你自己"
- **🖼 生成我的星图卡片**:1200×630 分享卡 PNG,纯 Canvas 本地绘制、本地下载
- 页面里的"编码说明"逐条回扣课程考点(视觉通道、交互、清洗、工作流)——这一页本身就是第 30 个演示

数据全部来自 lesson.js 的本地遥测(localStorage,键 `vis.stars.v1`),只记录
"读过哪些节、玩过哪些演示、题目对错、停留秒数、鼠标/滚动里程",**不产生任何网络请求**。

## 课堂授课模式(为讲课设计)

页面右下角 **"📽 进入课堂模式"** 按钮(或直接打开 `页面?teach=1`)一键切换为授课投屏模式:

| 能力 | 说明 | 快捷键 |
|------|------|--------|
| 投屏排版 | 字号整体放大、对比度增强,后排也能看清 | `T` 进出 |
| 逐点推进 | 按知识点翻页,当前小节呼吸徽章 + 闪光定位,**兼容翻页笔** | `← →` / `PgUp PgDn` |
| 聚光灯 | 鼠标区域高亮、四周变暗,"看这里"不再靠喊 | `L` 开关,`[ ]` 调半径 |
| 黑屏幕布 | 屏幕全黑"请看向讲台",瞬间拉回注意力 | `B` |
| 课堂计时 | "给大家 2 分钟玩这个演示"——大字倒计时,到点提示音 | `1`–`9` 启动 n 分钟 |
| 演示放大 | 任一演示全屏放大讲解,交互仍然可用 | `D`,或演示区 `⛶ 放大` |
| 屏幕画笔 | 在当前课件上直接圈画重点,双击清空 | `P`,`[ ]` 调粗细 |
| 板书白板 | 一键打开全屏白板,支持黑/红/蓝三色 | `W` |
| 激光笔 | 隐藏鼠标箭头,用高亮红点引导视线 | `G` |
| 教师提词 | 按当前知识点显示问法、强调点、演示时机与易错点 | `N` |
| 章节速览 | 九章总览,课堂中直接切章并保持授课模式 | `O` |
| 随机点名 | 本地保存班级名单,滚动抽取一名同学 | `R` |
| 秒表 / 字号 | 正计时;投屏字号在默认、大、特大之间循环 | `S` / `Z` |
| 随堂一问 | 每章 2 道嵌入关键小节的选择题,先猜后验证,防走神 | 点击作答 |
| 本章回顾 | 每章末自动注入要点回顾 + 下章预告 | — |

控制条上的 **`🧰 工具`** 可直接点选全部授课工具,**`?`** 随时查看快捷键;
`Esc` 关闭当前浮层或工具,`0` 停止计时。
课堂模式在当前标签页内会记住,刷新或切章仍保持授课状态;关闭标签页后自动恢复学生视图。

## 课堂互动三件套:猜、举、评

| 组件 | 位置 | 玩法 |
|------|------|------|
| 🔮 **先猜后看**(演示竞猜,13 题) | 各章关键演示的**正前方** | 全班先押一个答案 → 玩演示验证 → 点「看答案」;押注会记入学习星图 |
| ✋ **全班举手统计** | 每张竞猜卡 / 随堂一问卡下方 | 老师念完题让大家举手,按选项点 `+1`,分布**柱状图当场长出来**——本身就是一次实时可视化 |
| 💬 **讨论墙**(9 章 + 首页) | 各章末(本章回顾之后)、首页「课程留言板」 | 按 💡想法 / ❓提问 / 🌟打气 / 🔥吐槽 发言,便签墙展示,可 👍 点赞;**「复制全墙」一键导出纯文本**,发给老师 / 班群即可上交 |

讨论墙与举手统计均为纯本机数据(无后端、零上传):课堂上老师投屏边问边记,
课后学生复制全墙上交讨论作业;发言数、竞猜次数都会汇总到首页学习星图的观测报告里。
