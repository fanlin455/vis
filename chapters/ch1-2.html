D3.js 入门与 SVG 基础

D3(Data-Driven Documents)的名字就是它的全部思想:用数据驱动文档。 在动手 D3 之前先认识 SVG——网页上所有矢量图表的"原生语言"; 再理解 D3 最核心也最容易被初学者卡住的机制:选择集 + 数据绑定。

SVGD3 选择集数据绑定比例尺

🎯 学习目标

  • 认识 SVG 坐标系与 rect / circle / line / path / text 五类基本元素
  • 理解 selectAll → data → enter / update / exit 的数据绑定流程
  • 掌握 scaleLinear 线性比例尺,明白"为什么需要比例尺"
  • 能用 D3 的链式语法写出第一版"数据驱动"的柱状图
KP 2.1

SVG:网页矢量图形的积木

SVG(Scalable Vector Graphics)用 XML 描述图形:每个图形是一个标签, 每个标签是一个DOM 元素。这带来两个关键性质:

  • 无限缩放不失真:存的是"圆心 + 半径"这样的几何指令,不是像素阵
  • 每个元素可单独交互:能像网页文字一样被选中、绑定事件、加 CSS 动画

SVG 坐标系以左上角为原点,x 向右、y 向下——y 轴向下这一点和数学课的习惯相反, 画柱状图时必须手动"翻转"(见 2.3)。

💡 五类积木就能拼出几乎所有统计图表:矩形(柱)、圆(散点/节点)、线(折线/坐标轴)、 路径(任意曲线/饼图扇区)、文本(标签)。复杂的 <path> 只是折线段的紧凑写法。
svg-basics.html
<svg width="400" height="200" viewBox="0 0 400 200">
  <!-- 矩形:x,y 为左上角 -->
  <rect x="20" y="140" width="40" height="50" fill="#2f6fed"/>

  <!-- 圆:cx,cy 为圆心 -->
  <circle cx="120" cy="150" r="25" fill="#0ea5a5"/>

  <!-- 线:x1,y1 → x2,y2 -->
  <line x1="180" y1="60" x2="280" y2="160" stroke="#f59e0b" stroke-width="4"/>

  <!-- 路径:M 移动到,L 连线到,Z 闭合 -->
  <path d="M 300 160 L 330 100 L 360 160 Z" fill="#8b5cf6"/>

  <!-- 文本 -->
  <text x="200" y="30" text-anchor="middle" font-size="14">SVG 基本元素</text>
</svg>

KP 2.2

选择集与数据绑定:D3 的心脏

原生写法是"先有元素,再填内容";D3 反过来:先声明数据,让数据自己去"长出"元素。 核心三步:

  • d3.select / selectAll:选中(或准备好)一组元素
  • .data(arr):把数组逐项绑定到元素上,按索引配对
  • .join(enter ⇒ …, update ⇒ …, exit ⇒ …):数据比元素多的部分进 enter(创建新元素), 少的部分进 exit(移除旧元素),配对成功的进 update(原地更新)

这套机制的威力在数据变化时显现:新数据到来,图表不是推倒重来, 而是"多的补、少的删、对应的改"——页面上的每个柱子保持身份连续,过渡动画因此才成为可能。

💡 记忆法:数据是宾客,元素是座位。join 就是"来宾入座、多余宾客加座、空座撤走"。
d3-bind.js
const data = [30, 86, 60, 45];

const bars = d3.select("svg")
  .selectAll("rect")                 // 1. 准备选择集(可以为空)
  .data(data, d => d);              // 2. 绑定数据(按值配对)

bars.join(
  (enter) => enter.append("rect")           // 数据多了 → 新建
          .attr("class", "bind-bar")
          .attr("x", (d, i) => i * 60)
          .attr("width", 40),
  (update) => update                         // 数据变了 → 原地改
          .transition().duration(600)
          .attr("y", d => 180 - d)
          .attr("height", d => d),
  (exit) => exit.remove()                    // 数据少了 → 移除
);

演示 · enter / update / exit 实况

■ enter:新建(绿) ■ update:更新(蓝) ■ exit:移除(红,淡出) data = []
提示:点「换一批数据」数次,注意观察:值相同的柱子保持不动,新值从底部绿色长出,消失的红色淡出——这就是 join 的三路分发。
KP 2.3

比例尺:从数据世界到像素世界

数据的取值范围千奇百怪:气温 −20~40 ℃、GDP 数万亿、百分比 0~100。 屏幕却只有几百像素。比例尺(Scale)就是两个世界之间的换算函数:

像素位置 = scale(数据值)  ·  scale = d3.scaleLinear()
.domain([数据最小, 数据最大]).range([像素最小, 像素最大])

为什么不直接拿数据当像素?三个理由:

  • 自适应:数据更新(最大值变了)时,只需重算 scale,所有元素统一重排
  • 防越界:保证任何数据都被映射进画布内,不会画出屏幕
  • 坐标轴配套:刻度线由 scale 生成,图和轴永远一致
⚠️ y 轴翻转陷阱:SVG 的 y 向下,所以柱状图的 range 要写 [height, 0](大值 → 小 y), 柱子才会"向上长"。漏掉这一步是初学者第一张图"倒着长"的头号原因。
d3-scale.js
const W = 600, H = 200, PAD = 30;
const data = [12, 45, 30, 68, 25];

// 线性比例尺:数据 → 像素。注意 y 方向 [H-PAD, PAD] 的"翻转"
const y = d3.scaleLinear()
  .domain([0, d3.max(data)])          // 输入域:0 到数据最大值
  .range([H - PAD, PAD]);             // 输出域:底部到顶部(y 向下!)

svg.selectAll("rect")
  .data(data)
  .join("rect")
  .attr("x", (d, i) => PAD + i * 90)
  .attr("y", d => y(d))              // 关键:高度先过比例尺
  .attr("height", d => y(0) - y(d))
  .attr("width", 60);

// 坐标轴:刻度由同一个 scale 生成,天然对齐
svg.append("g")
  .attr("transform", `translate(0,${H - PAD})`)
  .call(d3.axisBottom(x));
