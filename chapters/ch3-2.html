专题:表格可视化

表格常被当作"没法可视化才用的备胎",其实它是精确阅读的王者: 图表利于比较与发现模式,表格利于查值与核对。 而当表格遇上排序、筛选、迷你图,它本身就是一件交互式可视化作品。

KP 8.1

坏表格 vs 好表格:六个反模式

同一份数据,左右两张表,信息获取效率天差地别。常见反模式:

  • 垂直边框全开:网格线喧宾夺主,数字列无法纵向扫读
  • 数字居中对齐:个位十万位错位,大小比较失能——数字必须右对齐
  • 无数字格式化:1234567 应显示为 1,234,567;0.156 应显示为 15.6%
  • 斑马纹滥用:高对比条纹干扰扫读,浅色或仅 hover 高亮更佳
  • 重复冗余:每行重复相同类别,应合并单元格或分组行
  • 列宽失控:长文本挤压数字列,关键列应固定宽度
💡 判断标准:读者最快能否纵向扫一列比较大小、横向扫一行找到记录?表格设计的一切都服务这两条扫读路径。

KP 8.2

排序与筛选:表格的原生交互

图表的交互靠拖拽刷选,表格的交互靠排序与筛选——成本低、用户零学习成本、 且与 Excel 心智模型完全一致。实现要点:

  • 点击表头循环降序 → 升序 → 原序,箭头即时反馈当前状态
  • 搜索框输入即时过滤(includes 即可,中文场景无需分词),并始终显示"当前 n / 总 m 条"
  • 筛选为空时给出友好空态,而不是白屏
  • 排序图标加 aria-sort,屏幕阅读器也能感知——可访问性是可视化的底座
table-sort.js
let sortKey = null, sortDir = -1;              // -1 降序,1 升序

function render(rows) {
  tbody.selectAll("tr").data(rows, d => d.id)
    .join("tr")                                // 数据驱动,和图表同源
    .html(d => `<td>${d.name}</td><td style="text-align:right">${d.score}</td>…`);

  th.attr("aria-sort", d =>
    d.key === sortKey ? (sortDir < 0 ? "descending" : "ascending") : null);
}

th.on("click", (e, d) => {                     // 三态循环
  if (sortKey === d.key && sortDir === -1) { sortKey = null; sortDir = -1; }   // 回原序
  else sortDir = (sortKey === d.key) ? -sortDir : -1, sortKey = d.key;
  render(sort(rows, sortKey, sortDir));
});

search.on("input", () =>                       // 实时过滤
  render(rows.filter((r) => r.name.includes(search.node().value))));

KP 8.3

Sparkline:表格里的微图表

Sparkline(迷你图)是 Tufte 提出的"文字大小的图表":一条 80×24 像素的折线, 塞进表格单元格里,一列趋势信息就此诞生—— 每行既有精确数值,又有 12 个月的趋势形状,查值与洞察兼得。

  • 迷你图不要 y 轴:只看形状,绝对值由旁边的数字列负责
  • 同一列的迷你图共享 y 域(0 到该列最大值),否则形状不可跨行比较
  • 终点(最新值)加一个圆点、涨跌用红绿,一眼锁定"现在"
  • 悬停显示逐月数值——微图表也能有完整 tooltip
💡 金融终端(Bloomberg 等)、GitHub 提交热图旁的贡献曲线、Google Analytics 的趋势列,全是这一模式的工业化应用。
sparkline.js
function sparkline(values, w, h, yScale) {
  const pts = values.map((v, i) =>
    [i * (w / (values.length - 1)), yScale(v)]);   // 共享 yScale,形状可比

  const path = "M " + pts.map(p => p.join(",")).join(" L ");
  const last = pts[pts.length - 1];
  const up = values.at(-1) >= values[0];

  return `<svg width="${w}" height="${h}">
    <path d="${path}" stroke="${up ? "#0b6a4a" : "#b91c1c"}"
          stroke-width="1.6" fill="none"/>
    <circle cx="${last[0]}" cy="${last[1]}" r="2.4"
            fill="${up ? "#0b6a4a" : "#b91c1c"}"/>   // 终点 = 现在
  </svg>`;
}

// 关键:整列共享同一个 y 域
const yScale = d3.scaleLinear()
  .domain([0, d3.max(allRows, d => d3.max(d.trend))])
  .range([h - 3, 3]);
