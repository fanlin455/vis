KP 6.1

数据加载与清洗:垃圾进,垃圾出

可视化界有条铁律 GIGO(Garbage In, Garbage Out):数据不干净,图表越精美越误导。 三类最常见的脏数据各有对策:

  • 缺失值(空单元格):数值型用中位数填充或整行剔除;类别型标"未知"——绝不能当 0 处理
  • 类型错乱:CSV 里一切都是字符串,"+120"、"1,200"、"120件" 都要解析成数字
  • 异常值:单价 3 万元一杯的奶茶,可能是录错的小数点;先 filter 再看分布,或用分位数截尾
💡 工程习惯:清洗函数保持纯函数(输入原始数据,返回干净数据),并打印清洗日志(删了几行、改了几个值)——未来的你会感谢这份日志。
clean.js
const raw = await d3.csv("sales.csv", d3.autoType);   // autoType 尝试自动转类型

function clean(rows) {
  const log = [];
  const out = rows.filter((r) => {
    if (r.price == null || Number.isNaN(+r.price)) {   // 缺失 → 剔除并记日志
      log.push(`删除缺失行:${r.id}`);
      return false;
    }
    return true;
  }).map((r) => {
    const price = parseFloat(String(r.price).replace(/[,¥]/g, "")); // "1,200" → 1200
    if (price > 10000) log.push(`截尾异常值:${r.id} ${price} → 10000`);
    return { ...r, price: Math.min(price, 10000) };
  });
  console.log(log.join("\n"));
  return out;
}

KP 6.2

层级布局:同一棵树的两种长相

文件目录、组织架构、预算科目——现实里大量数据天生层级。 D3 用 d3.hierarchy 把它们统一成"节点树 + 数值"的抽象, 再交给不同布局算法生成坐标:

  • 缩进树(indent tree):每层缩进一格,适合行数不多、要读文字的场景
  • 矩形树图(treemap):把父节点矩形按子节点数值占比切分,面积 = 数值,一屏看穿"钱/量都花在哪"

树图切分的关键是 d3.treemapTileSquarify:让小矩形尽量接近正方形, 人眼比较面积才不失真(细长条的面积极难估)。

💡 点面积图里的矩形 = 选中该分支;缩进树会同步高亮"根 → 该节点"的路径。两图共用同一份数据与选中状态,这就是第 5 章联动的复用。
treemap.js
const root = d3.hierarchy(budget)               // {name, value, children}
  .sum(d => d.value)                            // 自底向上汇总数值
  .sort((a, b) => b.value - a.value);           // 大块在前,布局更稳

d3.treemap()
  .size([W, H])
  .paddingInner(2)
  .tile(d3.treemapTileSquarify)                 // 近正方形切块
  (root);

svg.selectAll("rect")
  .data(root.leaves())
  .join("rect")
  .attr("x", d => d.x0).attr("y", d => d.y0)    // 布局算好的坐标
  .attr("width", d => d.x1 - d.x0)
  .attr("height", d => d.y1 - d.y0)
  .attr("fill", d => color(d.parent.data.name)); // 父分支定色

KP 6.3

组装仪表盘:让视图互相成全

仪表盘不是图表的堆砌,而是一个分层的信息系统:

  • KPI 层:今天最重要的 3 个数字,一行大字,先给结论
  • 结构层:柱状图回答"哪类最大/最小"(比较)
    • 趋势层:折线图回答"随时间怎么走"(变化)
  • 联动:一处刷新,处处刷新——所有视图读同一份状态
💡 布局口诀:结论在上,比较在中,细节在下;从左到右是时间,从上到下是从结论到证据。
dashboard.js
async function refresh() {
  const data = await fetch("/api/metrics").then(r => r.json());

  // KPI:数字滚动过渡,变化的幅度用颜色标注
  kpiTotal.transition().tween("text", () => tweenNum(old.total, data.total));
  kpiDelta.text(fmtPct(data.total / old.total - 1)).attr("class", ...);

  // 柱 & 线:所有视图重绘都带 600ms 过渡,保持节奏一致
  bars.data(data.byCategory).transition().duration(600).attr(...);
  line.datum(data.timeline).transition().duration(600).attr("d", ...);

  old = data;      // 记住旧值:差值计算与补间起点都依赖它
}
setInterval(refresh, 5000);   // 轮询刷新;实时系统换 WebSocket

演示 · 迷你仪表盘(KPI + 结构 + 趋势,一键刷新)

提示:刷新时注意三件事同时发生——KPI 数字跳变并标出涨跌、柱子高度过渡、折线重画。同步的节奏感是"一个系统"而非"三张图"的关键。
