KP 7.1

ECharts:写配置,不写指令

用 D3 画柱状图,你要自己建比例尺、画坐标轴、挨个摆矩形——这是命令式: 告诉浏览器"每一步怎么做"。ECharts 反其道而行:声明式—— 你只描述"要什么"(数据、图类型、颜色),渲染引擎包办全部细节。

  • 上手快:一个 option 对象出一张图,文档、示例库极其完善(中文友好)
  • 默认好看:主题、tooltip、动画、移动端适配全部内置
  • 代价:非标准布局(如课程路径图)很难实现;细节控制权少于 D3
  • 默认 Canvas 渲染,大数据量与「large」模式表现好;可切 SVG 渲染器省内存
💡 一句话记范式:D3 是"给你乐高"(指令),ECharts 是"给你成品柜,你填参数"(配置)。 业务报表选配置式,研究型/定制型作品选指令式。
echarts-quick.js
const chart = echarts.init(document.getElementById("chart"));

const option = {
  title:  { text: "月销量" },
  tooltip: { trigger: "axis" },          // 悬停提示:内置,零代码
  xAxis:  { type: "category", data: ["1月","2月","3月","4月","5月","6月"] },
  yAxis:  { type: "value" },
  series: [{
    name: "销量",
    type: "bar",                          // 换 "line" / "pie" 即换图型
    data: [120, 200, 150, 80, 270, 310],
    itemStyle: { color: "#2f6fed", borderRadius: [5,5,0,0] }
  }]
};

chart.setOption(option);    // 之后改 option 再 setOption → 自动 diff + 动画过渡

演示 · 左改配置,右看结果(模拟 setOption)

提示:真实 ECharts 中,切换 type 只是改 option 里一个字符串再 setOption——引擎自动完成销毁与重建。本演示用 SVG 手工模拟其效果。
KP 7.2

选型决策树:三问定工具

面对新项目,按顺序问自己三个问题,基本就能锁定工具:

  • 一问规模:数据点几千以内,任何库都行;十万级以上,必须 Canvas/WebGL 阵营
  • 二问定制:标准图表(报表、监控)→ 配置式;独创布局、叙事型作品 → 指令式(D3)
  • 三问领域:地理大数据 → deck.gl/Kepler.gl;科学计算 → Plotly;探索分析 → Observable
💡 团队因素同样真实:文档语言、社区活跃度、招人难度,都该进入决策——技术上"次优"但团队都会用的工具,往往是工程上的"最优"。
